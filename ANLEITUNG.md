## So laden Sie hoch (Safari, GitHub Lazoooisbackk/Project-1)

1. Auf GitHub **Add file → Upload files**.
2. Im Finder diesen Ordner öffnen, alle Einträge markieren (Cmd+A) und ins Browserfenster ziehen. Nicht den Ordner selbst ziehen, sondern seinen Inhalt.
3. Warten, bis alle 9 Dateien in der Liste stehen (plus diese Anleitung, die stört nicht).
4. Als Nachricht: `Paket 2: Versprechen, Beweis, Ablauf, Person` und **Commit changes** drücken.
5. Vercel baut in etwa 20 Sekunden. Danach mir „hab“ schreiben, ich prüfe live.
